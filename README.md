# Mobile Applications – MCQ Practice

An interactive study and revision website for **Mobile Applications** students at **Atlantic Technological University (ATU), Sligo**.

The app helps students prepare for their Kotlin and Jetpack Compose MCQ assessment through individual practice quizzes and a full mock examination.

## Features

- **12 Individual Quizzes** organised into Sections 1–4.
- **120 Practice Questions** covering Kotlin and Android development.
- **40-Question Mock Examination** worth 20 marks.
- Four answer options per question, with one correct answer.
- Immediate feedback and explanations during individual quizzes.
- Results and answer explanations after submitting the mock examination.
- Automatic scrolling between questions.
- Score tracking and review of incorrect answers.
- Progress saved locally in the browser.
- Responsive design for laptops, desktops, tablets and phones.
- ATU-inspired colour scheme.

## Mock Examination

The mock examination is designed to reflect the format and difficulty of the Mobile Applications MCQ assessment.

- 40 multiple-choice questions
- Four options per question
- One correct answer per question
- 0.5 marks per question
- Total: 20 marks
- Answers and explanations available after submission

## How to Use

1. Open the study app using the GitHub Pages website link.
2. Select **Individual Quizzes** to practise a specific topic.
3. Answer the questions and check your understanding.
4. Review explanations for the correct answers.
5. Select **Mock Examination** to test your knowledge across all four sections.

## Running Locally

The website can also run without an internet connection.

1. Download the repository files.
2. Open `index.html` in any modern web browser.
3. Begin practising.

No installation, database or additional software is required.

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- GitHub Pages

## Student Progress

Student progress is stored locally in the browser. No account or login is required.

Progress is specific to the browser and device being used and is not automatically synchronised across devices.

## Educational Purpose

This resource is designed to support learning and revision in Kotlin, Android Studio and Jetpack Compose.

The practice questions reinforce the material covered in Sections 1–4 of the Android Basics with Compose curriculum.

The questions are intended for revision and are not copies of the actual Moodle examination.
